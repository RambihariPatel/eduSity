# 🎓 Edusity - Learning Platform

🚀 Live Demo: https://edusitybyram.netlify.app/

Edusity is a modern and responsive educational platform designed to help users explore courses, manage learning tasks, and enhance productivity. This project showcases my frontend development skills along with clean UI/UX design.

---

## 📌 Features

- 📚 Browse educational content
- 📝 Task management system
- ⏱️ Built-in timer for productivity
- 📱 Fully responsive design (Mobile + Desktop)
- ⚡ Fast performance using modern web technologies
- 💾 Data persistence using localStorage

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Flexbox, Grid, Media Queries
- **Storage:** LocalStorage
- **Deployment:** Netlify
